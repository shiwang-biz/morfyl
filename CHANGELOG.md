# Changelog

## 0.2.0
- **One-click engines.** Every engine except the built-in ImageMagick and FFmpeg installs from the Engines tab with
  one click, including **LibreOffice** (Office files) and **Calibre** (ebooks). They go into Morfyl's own folder:
  no admin password, and nothing else on the computer changes. **Install all missing** installs everything at once.
- **Install guides.** Each engine has a step-by-step "How to install" guide for macOS and Windows.
- Conversions that need a missing engine show an **Install** button right in the queue.
- Engines Morfyl installed can be removed again from the Engines tab.

## 0.1.1
- Images can now be converted to PNG and TIFF.
- Fixed image formats showing as "unavailable".
- Fixed macOS saying the app "is damaged and can't be opened".
